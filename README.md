# The API Project
This is a project on Data Extraction via API.

In this API project, we've decided to select a random API from the RapidAPI marketplace to explore and get a hands on experience on how to **Ingest/Extract Data** from an API source.

We've decided to go with a YouTube API from the RapidAPI marketplace.
The API retrieves many types of data from Youtube.

Here's the Youtube API provider link: 
https://rapidapi.com/Glavier/api/youtube138/playground/apiendpoint_b2210da2-97ee-4448-b916-c8b83789df5c

1. Create an account on RapidAPI.com. It is free!

2. Open the link to the API provider. Copy the link above.

    ***YOU WILL HAVE TO SUBSCRIBE TO THIS API PROVIDER TO CONTINUE***

    So click the "**Subscribe to Test**" blue button at the top of the **RIGHT Panel**.

In the YouTube API provider page:

3. Look to the **LEFT Panel** to discover the various endpoints the API provider offers.

    In the "**Channel**" category, there are many endpoints BUT we're going to use the "*GET Channel Videos*" endpoint. So, click on: **>> Channel** > **GET Channel Videos**

4. Look to the **RIGHT Panel** to see the sample *Code Snippet* for your choosen endpoint.
Click the "**Target:**" dropdown and select '*Python*'
Click the "**Client:**" dropdown and select '*Requests*'

The entire *Code Snippet* you see is what we're going to need in this project.

***NOTE:*** Ideally in a real world data engineering project, your project manager should be able to provide you with most of the API details you will need like this code snippet.
